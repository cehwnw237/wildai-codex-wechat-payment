## 先说结论：Codex 本身不收微信支付

Codex 的使用权限是挂在 ChatGPT 订阅上的，不是单独卖的一个商品。按 OpenAI 官方现在的说明，Plus（20 美元/月）就包含 Codex 的扩展访问；Pro 有 100 美元和 200 美元两档，两档核心能力相同，主要差别是使用额度，Codex 都在里面。

这三档在国内都刷不了微信。原因很朴素：OpenAI 的结账走 Stripe 那条卡组织通道，微信支付和支付宝不在列表里。你换浏览器、换 IP、换账单地址都不解决这个问题。

还有一件跟付款无关但必须先知道的事：截至 2026 年 8 月 20 日核验的信息，OpenAI 的 ChatGPT 支持地区列表里并没有中国大陆。第三方代付平台只解决“钱怎么过去”，不改变 OpenAI 的地区和账号规则。你的账号本身在用哪个地区、IP 稳不稳定，是另一套风险，跟本文讲的付款方式是两码事。
